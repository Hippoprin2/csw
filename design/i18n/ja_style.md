# 일본어 말투·용어집 (초안, 원어민 검수 전)

결정: T3 A — 단짝 대사·안내는 부드러운 반말(タメ口), 버튼은 짧은 기본형, **동의·약관·결제·안전 안내 문구만 です・ます** (법적 문구와 상담 안내가 반말이면 가벼워 보임).

## 규칙
- 한자 적게, 히라가나 많이 (단짝 앱의 부드러운 톤). 예: 種 → たね, 瓶 → びん
- '승리' = 勝ち (勝利는 딱딱함)
- 카운트다운·압박 금지 원칙 그대로: あと◯個 같은 표현 금지
- 조사 문제 없음: 일본어는 이름 뒤 が/は 하나라 `${pet}が` 로 고정
- 이모지 없음(앱 UI 원칙)

## 용어집 (T6, 원어민 검수 때 확정)
- 단짝 → あいぼう
- 씨앗 → たね
- 구슬 → ビー玉
- 유리병 → ガラスびん
- 텃밭 → 菜園(さいえん) / 마당 → にわ / 방 → へや
- 오늘의 쪽지 → きょうのメモ
- 버틴 하루 → 후보 ふんばった日 ← 추천(버티다 = 踏ん張る, 가장 가까움) / がんばった日(성취처럼 들림) / のりこえた日(다 지나간 느낌) — 원어민 검수에서 확정
- 분류 8종: 정리 → かたづけ / 운동 → からだ / 공부 → べんきょう / 업무 → しごと / 잘 먹기 → ごはん / 나 돌보기 → じぶんケア / 사람 → ひと / 응원 → おうえん

## 예시 번역 (실제 앱 문구에서)
- 오늘 해낸 거, 아무리 작아도 좋아 → 今日できたこと、どんなに小さくてもいいよ
- 물 한 잔 마신 것도 승리야. 오늘은 뭐 했어? → 水を一杯飲んだのも勝ちだよ。今日はなにした？
- 침대 정리도, 답장 하나도 다 승리야. 오늘은? → ベッドを整えたのも、返信ひとつも、ぜんぶ勝ち。今日は？
- 오늘의 작은 승리, 들려줄래? → 今日の小さな勝ち、聞かせてくれる？
- 오늘 너를 위해 한 일 하나만 적어볼까? → 今日、自分のためにしたこと、ひとつ書いてみる？
- ${pet}가 오늘 이야기 듣고 싶대 → ${pet}が今日のお話を聞きたいって
- 첫 구슬이 유리병에 들어갔어! → はじめてのビー玉がガラスびんに入ったよ！
- 유리병이 꽉 찼어! 뚜껑 닫아서 선반에 올려둘게. 새 병 시작이야 → ガラスびんがいっぱいになったよ！ふたをして棚にかざっておくね。新しいびんのはじまり
- 오늘 씨앗은 다 모았어. 기록은 계속 담겨 → 今日のたねはぜんぶ集まったよ。記録はいくつでも残せるよ
- ${c.name} 냠냠, 고마워! → ${c.name}、もぐもぐ。ありがとう！
- 이 이름으로 할래 / 나중에 정할게 / 시작하기 → この名前にする / あとで決める / はじめる
- [필수] 민감정보 처리에 동의해요 → 【必須】要配慮個人情報の取り扱いに同意します
- 이 앱은 상담·치료 서비스가 아니라는 걸 알아요 → このアプリはカウンセリングや治療のサービスではないことを理解しています
- 뿡! (탭 반응 클립 글자) → ぷっ!
