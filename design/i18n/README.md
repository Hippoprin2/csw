- P1 번역 뼈대 (개발 스레드, 1~2일): expo-localization + i18next, 스크립트로 한글 문자열 추출 → `locales/ko.json`, 화면은 `t('key')`. eslint 규칙으로 화면 코드에 한글 직접 쓰기 금지(새 코드도 자동으로 따라오게). 조사 함수(ko)
- P2 언어 로직 (1~2일): classify 프롬프트 언어별(분류 키는 그대로 9종), 일본어 키워드·자해 키워드, 일본어 평가 세트로 위험 20/20·오탐 0~1 목표, harm_others 일본어 평가, 알림, 글꼴(가나 되는 OFL 둥근 글꼴 — Zen Maru Gothic / M PLUS Rounded 1c 후보), '뿡!' 일본어판 클립(ぷっ!), 국가별 상담 번호·로그인 버튼
- P3 번역 (반나절 + 검수): 용어집·말투 먼저 정하고 AI로 ja.json 생성 → 원어민 검수 1회(핵심 화면·단짝 대사·안전 문구·스토어 문구)
- P4 레이아웃 QA (반나절): 언어 × 기종 캡처 → 넘침 자동 검출 → 고침 → 비교 시트
- P5 스토어 (반나절, Apple 계정 뒤): 일본어 스크린샷 자동 생성, 일본어 ASO 키워드 조사, API로 등록
