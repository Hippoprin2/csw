기록 다시 보기 · 들어가는 길

화면은 3종류(유리병 탭 · 목록 화면 1개 · 하루 한 장) + 어디서든 열리는 '크게 보기' 시트. 깊어도 2단계 + 시트.
탭 1

방

  • 입력창 (그대로 1줄)
  • 오늘의 쪽지 → 쪽지 누르면 시트
  • "다 보기" → 하루 한 장(오늘)
탭 2

유리병 탭

  • 맨 위 카드 1자리 (한 달 카드 / 주간 카드 / 한 달 전 오늘)
  • 지금 병 + 선반
  • 칩 줄: ☆ · 분류들
  • 최근 2주 목록 (날짜 제목)
화면

하루 한 장

  • 목록 날짜 제목 · 쪽지 "다 보기"
  • 좌우로 기록한 날만 넘김
  • 줄 누르면 → 시트
화면

목록 화면 (하나)

  • ☆ 칩 → 다시 보고 싶은 기록
  • 분류 칩 → 그 분류만
  • 찾기 결과도 같은 모양
  • 줄 누르면 → 시트
시트

크게 보기

  • 기록 글 크게 + 적은 시각
  • 단짝 동작 자동 재생
  • + 한 줄 더 남기기 (메모)
  • ☆ 다시 보고 싶은 기록
  • 분류 칩 → 목록 화면
  • ··· 안에 고치기 · 지우기
