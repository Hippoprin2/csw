# 단짝(하마) 앱 에셋 v1

만든 곳: 캐릭터 스레드 (2026-11-08). 앱에 붙이는 작업은 앱 개발 스레드가 한다. 대상 파일은 `mobile/src/ui/Pet.tsx`.

## 파일
- `hippo_<key>.webp`: 움직이는 WebP, 600x800, 투명 배경, 24fps. 전체 약 13.9MB(18클립, 그림자 포함).
- `hippo_<key>_poster.png`: 첫 프레임(로딩 중이나 정지 화면용)
- `manifest.json`: 프레임 수, 길이(ms), 반복 여부

## key (앱 categories.ts 기준)
- 반복: `idle`(대기), `sit_loop`(곁에 앉기 유지)
- 한 번 재생: `tidy`(쓱싹+빗자루), `move`(점프+헤드밴드·땀), `study`(책상+공책), `work`(책상+노트북), `eat`(냠냠+군고구마), `care`(기지개+회전+반짝이), `people`(손 흔들기+편지), `cheer`(만세+점프+색종이)
- 곁에 앉기(자해 표현 대응, 조용한 동작): `sit_in`(앉기, 앉은 채로 끝남) → `sit_loop`(반복) → `sit_out`(일어나서 대기 자세로 끝남)
- 방 '먹이기': `eat`(군고구마), `eat_strawberry`(딸기). 꽃 '선물하기'는 `care` 재사용(WORLD.md)
- '잘 먹기' 세부 동작(2026-11-12 대표 결정 Z2): `drink`(물 마시기, 64f 2.7초, 한 번) — 기록 분류가 eat이고 본문에 '물'이 있으면 `eat` 대신 재생. `cook`(요리, 76f 3.2초, 한 번: 요리사 모자 + 코랄 프라이팬을 한 손으로, 계란후라이 뒤집기) — 본문에 '요리/만들/끓/볶'이면 재생
- 텃밭(카메라 25°, WORLD.md W2): `garden_idle`(반복), `garden_cheer`(수확 만세, 한 번). 방 클립(6.5°)과 섞어 쓰지 말 것. 25°에서는 색종이 시작 위치를 머리 위로 올려 렌더함
- 마당·텃밭 걷기(25°, 2026-11-11): `walk_front`(아래로), `walk_back`(위로), `walk_side`(오른쪽, 왼쪽은 좌우 뒤집어 그림) — 모두 반복. 제자리 걷기라 위치는 앱이 옮긴다. 발 기준점은 텃밭 클립과 같다(303, 697). 발이 미끄러지지 않는 속도와 방향 고르는 법은 manifest `walk` 참고(대표 결정 0.9단위/초 = 가로 360px/s, 세로 153px/s, 단짝 w=435 기준. 클립 보폭 기준 속도는 0.42라 발이 조금 미끄러짐 — 감수하기로 함)
- 마당 아이템 동작(25°, 2026-11-11): 벤치 `sit_bench_in`/`_loop`/`_out`, 피크닉 매트 `sit_eat_in`/`_loop`/`_out` + 먹기 `sit_eat_strawberry`·`sit_eat_sweetpotato`(앉은 채 한 번, 앞뒤가 `sit_eat_loop` 자세), 해먹 `lie_in`/`_loop`/`_out`, 연못 `splash_in`/`_loop`/`_out`, 화단 `sniff`, 추억 나무 `show_fruit`(한 번씩). `_loop`는 4초(물장구 2초) 반복이라 5~10초 동안 돌린 뒤 `_out`. **클립의 발 점(303,697)을 manifest `yard_actions`의 `stand`에 맞춘다** — 벤치·해먹은 앞에 서는 새 stand(공간 manifest의 stand는 의자 위/천 가운데라 다름). 아이템이 하마 앞을 가리는 부분은 클립에서 이미 뚫려 있으니(홀드아웃) 아이템 그림을 먼저, 하마를 그 위에 그린다. 물장구 아랫몸도 물 높이에서 잘려 있음. 그림자는 의자 위·해먹·물속에서 꺼짐. 물장구 들어가기/나오기는 앱이 enter↔stand로 옮겨 줌(프레임 4~15 / 8~19)
- `work`는 새 카테고리다. '공부·일'을 공부(study)와 업무(work)로 나눴다(STATUS.md 결정 사항). 분류 로직과 문구 추가가 필요하다.

## 바닥 그림자 (2026-11-10)
- 모든 클립에 부드러운 타원 그림자가 들어 있다. 점프하면 작아지고 옅어지며, 앉으면 조금 넓어진다. **앱에서 그림자를 따로 그리지 않는다.**
- 바닥 기준점(발이 닿는 곳, 600x800 프레임 기준): 방 6.5° 클립 = (303, 713), 텃밭 25° 클립 = (303, 697). 공간 그림에서 단짝 자리 바닥점에 이 점을 맞춰 얹는다.
- 그림자 때문에 프레임 아래쪽에 반투명 픽셀이 있다(방 y 674~727, 텃밭 y 658~743). 자를 때 이 영역을 남긴다.

## 재생 규칙
- 한 번 재생하는 동작은 모두 대기 자세로 시작해서 대기 자세로 끝난다. 그래서 idle → 동작 → idle로 바로 이어 붙여도 튀지 않는다.
- 동작이 끝난 시점은 `duration_ms` 타이머로 판단한다. 디코더의 반복 횟수 설정(loop=1)은 플랫폼마다 다르게 동작할 수 있다.
- 모든 클립의 카메라와 크기가 같다. 같은 크기와 같은 위치에 겹쳐서 바꿔 끼우면 된다. study/work 클립은 동작 안에서 카메라가 올라갔다 내려오고, 시작과 끝 프레임은 idle과 같다.
- 실기기에서 확인할 것: expo-image의 움직이는 WebP 재생, 메모리 사용량, 저가 안드로이드 성능.
