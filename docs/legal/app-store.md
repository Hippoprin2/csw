# App Store 제출용 답안 (초안)

> 초안 2026-11-12. App Store Connect에 입력할 때 쓰는 답안. 실제 질문 문구와 선택지는 입력 시점의 화면을 따른다(Apple이 자주 바꿈).
> 근거: 앱 코드·DB 스키마. 광고·추적 SDK 없음(`mobile/package.json`).

## 앱 개인정보(Privacy 라벨)

추적(다른 회사 앱·웹과 데이터를 묶어 광고에 쓰는 것): **안 함**

| Apple 분류 | 수집 | 이용자와 연결 | 용도 | 실제 내용 |
|---|---|---|---|---|
| 연락처 정보 › 이메일 주소 | 예 | 예 | 앱 기능 | 로그인, 로그인 코드 발송 |
| 연락처 정보 › 이름 | 예 | 예 | 앱 기능 | 카카오 닉네임, Google 이름 |
| 사용자 콘텐츠 › 기타 사용자 콘텐츠 | 예 | 예 | 앱 기능 | 기록 내용, 단짝 이름 |
| 식별자 › 사용자 ID | 예 | 예 | 앱 기능 | 계정 ID |
| 사용 데이터 › 제품 상호작용 | 예 | 예 | 분석 | `app_events` (이벤트 이름·메타, 기록 내용 없음) |
| 구입 항목 › 구입 내역 | 구독 연동 후 예 | 예 | 앱 기능 | 구독 상태 |
| 위치, 연락처, 사진, 건강, 금융 정보, 검색 기록, 진단 | 아니요 | – | – | 수집 안 함 |

확인이 필요한 것
- 기록은 자유 글이라 건강 관련 내용이 들어갈 수 있다. 앱이 건강 정보를 요구하거나 따로 분류해 저장하지 않으므로 "기타 사용자 콘텐츠"로 답했다. 자해 표현 감지는 익명 집계만 남긴다. Apple 기준상 "건강" 또는 "민감한 정보"로도 표시해야 하는지는 제출 전에 Apple 안내 문구로 다시 확인한다.
- 기록 내용이 OpenAI로 전송된다(식별자 없음). 제3자 AI로 개인 데이터를 보내는 경우 앱 안에서 명확히 알리고 동의를 받으라는 심사 지침이 있으므로, 온보딩 동의 문구와 처리방침에 OpenAI를 명시한다.

## 연령 등급

- 앱 이용 조건은 만 14세 이상(약관 제4조, 온보딩 체크).
- 설문 답안: 폭력·성적 내용·도박·약물 없음. 사용자 생성 콘텐츠 공유 없음(기록은 본인만 봄). 채팅·메시지 없음. 광고 없음.
- "건강·웰빙 주제" 문항이 있으면 예(자해 표현 감지와 상담 번호 안내가 있음).
- 설문 결과 등급이 14세보다 낮게 나오면, 더 높은 등급을 직접 고를 수 있는지 확인해 14세에 가장 가까운 윗 등급으로 맞춘다.

## 심사에 필요한 그 밖의 것

- 개인정보처리방침 URL(필수), 지원 URL(필수)
- 구독 앱 요건: 구독 화면과 앱 설명에 구독 이름·기간·가격, 이용약관(EULA)·처리방침 링크, 구매 복원 버튼
- 계정 삭제: 앱 안에서 가능(설정 › 계정 삭제) — 충족
- Apple로 로그인: 다른 소셜 로그인과 함께 제공 — 충족
- 심사용 로그인 방법: 이메일 코드 방식이라 심사자가 코드를 받을 수 없다. 심사 전용 계정과 고정 코드, 또는 심사 메모에 받는 방법을 준비한다
- 심사 메모에 적을 것: 상담·의료 앱이 아님, 자해 표현 감지 시 109 등 공공 상담 번호만 안내
