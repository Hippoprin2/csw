# CSW 아트 기준서 (ART BIBLE)

캐릭터, 공간, 아이템이 한 세계처럼 보이게 하는 기준이다. 공간·아이템 스레드는 새 에셋을 만들기 전에 이 문서를 읽는다.
- 관리: 캐릭터 스레드가 초안 작성(2026-11-08). 기준을 바꾸는 결정은 이 문서와 docs/STATUS.md '결정 사항'에 함께 남긴다.
- 캐릭터 상세 이력: docs/CHARACTER.md / 공간·아이템: docs/WORLD.md

## 1. 톤 한 줄
동물의 숲 + 무민. 둥글고 말랑한 3D, 졸린 듯 편안한 표정, 따뜻한 크림·파스텔. 자극 없이 "괜찮아, 잘했어" 하는 느낌.

## 3. 형태 언어
- 모서리는 모두 둥글게. 각진 박스 금지: 박스는 베벨(짧은 변의 약 25%, 3단) 또는 구/캡슐 기반.
  - 스크립트로 베벨할 때 `bmesh.ops.bevel(..., profile=0.5)` 필수(기본값 0이면 둥글지 않고 계단처럼 깎임). 큰 면 그라데이션 방지에 Weighted Normal 모디파이어.
- 실루엣은 단순하게. 디테일은 형태보다 색으로 표현한다(예: 책 = 표지 박스 + 종이 박스 + 줄 몇 개).
- 비율은 약간 통통하고 짧게(가구 다리 짧고 두껍게, 손잡이는 굵게). 실물보다 귀엽게 과장해도 된다.
- 텍스처 패턴이나 사실적 질감(나뭇결, 섬유)은 쓰지 않는다. 단색 면 + 조명으로 입체감을 낸다.
  - 단짝 표면 v2 (2026-11-13 대표 확정): 몸은 #F2CFA6 단색 + 매끈한 표면(얼룩·이음새 줄 없음), 살짝 부드러운 윤기(sheen 0.2). 털 질감은 쓰지 않는다(폰 크기에서 거칠어 보임). 모든 클립 렌더에 자동 적용 = scripts/blender/surface.py

## 4. 색 팔레트 (sRGB hex)

- 캐릭터 몸(크림 베이지): #F2CFA6 / 귀 안쪽 분홍: #EC968C / 눈썹·콧구멍 진갈색: #583628
- 나무(책상): #DBB080 / 나무(진한 쪽): #CC9E73
- 민트(의자): #9ED6C2
- 코랄(헤드밴드, 포인트): #ED5C61 / 오프화이트: #FCF7ED
- 노랑(고구마 속, 연필, 반짝이): #FAC740 ~ #FFDB59

## 5. 재질
- Principled BSDF 하나만 쓴다. Metallic 0, Roughness 0.5~0.9(대부분 0.6~0.85, 매트).
- 빛나는 것(반짝이, 화면)만 Emission 1~3을 쓴다.
- 투명·유리는 최소한으로. 필요하면 Alpha만 쓰고 굴절은 쓰지 않는다.

## 6. 크기 기준 (Blender 단위)
- 캐릭터 키 = 1.0 (발 z = -0.5, 귀 끝 z = +0.5), 앞이 -Y, 위가 +Z.
- 기준 치수: 의자 좌판 높이 0.14(바닥 기준) / 책상 높이 0.38 / 공책 약 0.26 x 0.18 / 노트북 0.24 x 0.16.
- 방·가구는 이 캐릭터가 실제로 쓸 수 있는 크기로 만든다(문 높이 약 1.3, 침대 길이 약 1.2 등은 공간 스레드에서 확정).

## 7. 조명·카메라·렌더 (모든 렌더 공통, 바꾸지 않기)
- 엔진 Eevee, 색 변환 **Standard**, Look None. Blender 기본값(AgX)을 쓰면 색이 바랜다.
- 조명은 SUN 4개(회전 각도 / 세기): key (50,0,30)/3.0, fill (60,0,-120)/1.2, rim (110,0,180)/2.0, bounce (150,0,0)/0.7. World 배경 세기 0.9.
- 카메라는 직교(ortho) 1.45, 타깃 (0,0,0.07), 방향 (0.35,-1,0.12) 정규화 x 10. 정면보다 살짝 옆에서 보는 3/4 구도다.
- 책상 장면만 고도 0.5까지 카메라가 부드럽게 올라갔다 내려온다(앞뒤 10프레임). 시작·끝 프레임은 기본 구도와 같다.
- 출력: 600x800, 투명 배경 PNG 시퀀스, 24fps. 단짝 클립에는 바닥 타원 그림자 포함(scripts/blender/render_clip.py). 공간 소품도 바닥에 닿는 것은 같은 방식의 부드러운 접지 그림자를 넣는다.
- 공간 장면에서 카메라를 바꿔야 하면 캐릭터 화면 크기가 같게 유지되는지 먼저 확인한다.
- 공간별 고도(2026-11-09 대표 결정): 방 = 0.12(위 기본값), 텃밭·마당 = 0.5. 텃밭·마당에 나오는 단짝 클립은 0.5로 따로 렌더한다(출시: 대기·만세만. 축하 동작은 방에서만 나옴). 방향(0.35, -1)과 조명은 같다.
- World 색은 바꾸지 않는다(새 World 기본 회색, 세기 0.9). 배경색을 World 색으로 넣으면 사방에서 비추는 조명이 돼서 단짝·소품 색이 밝게 날아간다. 배경은 메시로 만들거나 투명 렌더 후 합성한다.

## 8. 만드는 방식 (파이프라인)
- 소품·가구는 Blender Python 스크립트로 직접 만든다(scripts/blender/props.py 참고). 외부 에셋을 쓰지 않으므로 라이선스 문제가 없고, 수정·재생성이 쉽다.
- 복잡한 형태만 AI 이미지 → TRELLIS.2 → Blender 정리 순서로 만든다(docs/CHARACTER.md 참고). 이때도 팔레트와 재질은 이 문서 기준으로 다시 입힌다.
- 얼굴이나 그림 요소는 2D 이미지를 표면에 투영(데칼)한다. 입체 눈알 같은 사실적 표현은 쓰지 않는다(대표 피드백).
- 등장·퇴장은 스케일 0↔1 팝(살짝 1.05~1.1 오버슈트). 동작 클립의 시작·끝 자세는 대기 자세와 같아야 한다.
- 파일 위치: 스크립트는 scripts/blender/, 결과물은 design/<주제>/, 공유용 영상·스틸은 design/<주제>/.../share/.

## 9. 하지 말 것
- 사실적 질감, 날카로운 모서리, 강한 대비, 네온·형광색
- 캐릭터보다 시선을 끄는 큰 패턴이나 장식
- 성취를 크기로 차등하는 시각 장치(트로피 크기 차등 등). 게임 원칙과 같다.
- 렌더마다 조명이나 색 설정을 따로 쓰는 것(클립을 이어 붙이면 색이 튄다)

## 11. 앱 화면 UI (A 포근한 창, 2026-11-13 대표 결정)
그림(캐릭터·텃밭·마당·아이템)은 위 1~10번 기준 그대로. 그림을 둘러싼 앱 화면만 이 기준을 따른다. 코드 기준은 mobile/src/ui/theme.ts.
- 색: 바탕 #FFFFFF(순백, 2026-11-13 대표 결정 — 처음 시안 크림 #FBF6EC에서 변경), 글자 #4A3226, 보조 글자 #6E5848, 옅은 면 #F2F0EB, 카드·입력칸·탭 바 #F7F6F3(흰 바탕과 구분되는 아주 옅은 회백색), 줄 사이 #ECE9E3, 포인트 #2F7D6B(활성 배경 #E3F1EC, 활성 글자 #1F5F50), 위험 동작 글자 #A13A2A. 예전 주황 #ff8a5c·보라 #aaa2dc는 쓰지 않는다.
- 색 쓰는 규칙(새 기능 포함): 화면 코드에 색 값(#…·rgba)을 직접 쓰지 않는다. UI 색은 mobile/src/ui/theme.ts의 C, 화면 속 그림 소품 색(유리병·방/텃밭 바탕 등)은 ART에 이름을 붙여 넣고 쓴다. 바탕색을 또 바꾸면 theme.ts만 고치면 된다. `npm run lint`(eslint)가 직접 쓴 색을 오류로 잡는다(예외: theme.ts, 분류 색 lib/categories.ts, 마당 그림 YardScene.tsx).
- 모양: 둥글기는 두 계열만. 카드 22(R.card)~28(R.cardLg), 버튼·입력칸·칩은 높이의 절반(알약, R.pill). 판·시트 위 모서리 32(R.sheet).
- 테두리: 카드·입력칸에 1px 선을 쓰지 않는다. 바탕(흰색)·옅은 면·카드의 면 색 차이로만 구분한다. (유리병·선반처럼 화면 속 소품 그림의 선은 예외)
- 아이콘: 이모지 대신 선 아이콘(ui/Icon.tsx, 24 격자, 선 굵기 1.8, 둥근 끝). 씨앗 = 초록 잎 아이콘 + 숫자. 새 아이콘도 같은 규칙으로 Icon.tsx에 추가한다. 기록 분류 데이터의 이모지(lib/categories.ts prop)는 화면에 쓰지 않는다.
- 탭 바: 화면 아래 떠 있는 흰 알약(좌우 16, 아래 24, 높이 68), 활성 탭만 민트 알약 배경.
- 방·텃밭: 그림을 위쪽 가로 꽉(약 420), 위 모서리 32 바탕색 판이 그림 아래를 살짝 덮고 올라옴. 그림 위 바탕색 칩 2개(왼쪽 날짜+공간 이름, 오른쪽 씨앗). 판 안 순서: 텃밭/방/마당 전환(옅은 면 위 카드색 알약) → 제목 → 입력칸(카드색 알약 56) + 민트 원형 보내기 → 예시.
- 마당: 그림이 화면 전체, 판·전환 없음(좌우 넘기기). 위쪽 칩 2개 + 왼쪽 가장자리 '‹ 방' 손잡이(바탕색 반쪽 알약 44) + 탭 바 바로 위 왼쪽 '매트에서 같이 먹기'. 열리기 전엔 마당 그림을 흐리게 깔고 안내 카드 1장(남은 날 수 표시 안 함).
- 시트: 가운데 모달 대신 아래에서 올라오는 시트(위 모서리 32, 손잡이 막대). 주 버튼 = 민트 알약, 취소 = 글자 버튼. 위험 동작 = 옅은 면 알약 + 위험색 글자.
- 설정: 묶음별 카드, 줄 사이는 옅은 면 색 한 줄. 위험색 글자는 '모든 기록 지우기'만.
- 글꼴: 현재 시스템 글꼴. 시안의 Gowun Dodum(OFL 1.1) 도입 여부는 대표 확인 대기. 도입하면 OFL 고지문을 앱에 함께 넣는다.
