- 2026-10-19: 바로 MVP, 앱 형태 (Expo/React Native + Supabase 예정)
- 2026-10-19: 한국어 먼저
- 2026-10-19: 음성 기록 MVP에서 제외 (텍스트만)
- 2026-10-19: 게임 요소 도입 — 동물 펫/아바타, 기록 시 공통 애니메이션 7종 + 씨앗 보상 + 방 꾸미기
- 원칙: 성취 크기 차등 없음, 잃는 장치 없음, 경쟁 없음
- 2026-11-08 (기능→캐릭터): 펫은 미접속·기록 수로 슬퍼지거나 아프지 않음. 필요한 표정/동작 = 7종 축하 + 기본 + "곁에 앉기"(자해 표현 대응용 조용한 동작). 펫 성장은 MVP 이후, 누적 기록 기준만
- 2026-11-08 (기능→공간): MVP는 방 1개 + 소품 15~20개 제안 (첫 주 안에 다 못 사는 양). 첫날 첫 소품 구매 가능하도록 온보딩 선물 씨앗 6개
- 2026-11-08 (기능→유료화): 체험 후 구독 구조로 정해져 "핵심 무료" 제안은 폐기. 대신 구독이 끝나도 지난 기록 보기·내보내기·삭제, 펫·방, 안전장치(상담 안내)는 계속 무료로 둘 것을 제안 (기록을 돈으로 잠그면 잃는 장치). 씨앗은 기록으로만 얻는 구조 유지
- 2026-11-08 (기능→유료화): 처음부터 가입 필수 (Apple + 카카오 + 이메일 OTP) — 구독을 계정에 바로 연결 가능
- 2026-11-08 (기능→유료화): 구독형, 무료 체험 7일 → 월 3,000원 (대표 결정). 연간(24,000원)은 출시 때 내놓지 않고 재방문·유지가 확인된 뒤 추가. 세부 설계는 MONETIZATION.md. 기록은 무제한(횟수 제한·추가 기록 결제 없음) — 추가 매출은 꾸미기 쪽에서만 검토
- 2026-11-08 (전체): 지인 테스트 없이 MVP 바로 공개 출시, iOS 먼저 → 출시 전에 결제(사업자등록 등)·안전장치·개인정보처리방침이 모두 준비돼야 함
- 2026-11-08 (기능→전체): 이용 연령 14세 이상 (확정) — 대상 사용자 중 학생은 중2 이상으로 좁아짐
- 2026-11-08 (앱 개발→전체): Supabase 별도 프로젝트 `csw`(도쿄, 무료) 사용. 소품 18개·가격은 임시 데이터로 넣음 → WORLD 스레드가 확정하면 items 테이블만 바꾸면 됨. 펫은 프로토타입 SVG 임시 → 캐릭터 확정 시 mobile/src/ui/Pet.tsx 교체
- 2026-11-08 (앱 개발→안전): 자해 표현 판정은 기기 키워드 OR 서버 LLM (하나라도 걸리면 안내). 분류·판정 모델 gpt-5.4-nano
