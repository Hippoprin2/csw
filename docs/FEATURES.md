## 1. 기능 목록과 MVP 구분

표기: [MVP] 필수 · [이후] MVP 다음 · [보류] 근거가 생길 때까지 안 만듦 · [제외] 원칙 위반이라 만들지 않음

### 핵심 기능 (핵심 루프 그 자체)
- C1 성취 기록 [MVP] — 텍스트 1줄(최대 100자), 개수 무제한, 추천 칩 6개. 루프의 시작이라 빠지면 앱이 아님.
  - 정리 장치 (2026-11-08 결정, 횟수 제한·건당 결제 대신): 같은 날 같은 내용은 한 줄로 묶어 표시("물 마셨다 ×4", 구슬은 4개 그대로) / 기록 많은 날은 접어서 표시("오늘 23가지 · 펼치기") / 주간 돌아보기 하이라이트는 반복 적은 기록 우선 / 서버 남용 방지 하루 50개 (초과 시 "오늘은 충분히 많이 적었어, 내일 또 들려줘" 안내, 분류 AI 비용 상한 겸용)
- C2 동작 자동 분류 9종 + "바꾸기" [MVP] (2026-11-09 업무 추가, 2026-11-10 '버틴 하루' 추가 — 5장) — 축하가 "내 일을 알아들었다"고 느끼게 하는 핵심. 키워드 즉시 분류 → 서버 LLM 보정, 실패 시 키워드 결과 유지.
- C3 펫 축하 애니메이션 + 한마디 [MVP] — 앱의 감정적 보상. 기록·축하는 방에서만(2026-11-09, 텃밭·마당엔 입력창 없음). 한마디는 카테고리별 템플릿(카테고리당 5~8개).
- C4 씨앗 보상 [MVP] — 기록 1개 = 씨앗 3개, 하루 10개 기록까지 보상(최대 30), 기록은 무제한. 모든 기록 같은 양.
- C5 방 꾸미기 [MVP] — 씨앗으로 소품 구매·자동 배치. MVP는 방 1개 + 소품 18개(9~30씨앗, 합계 264, 정해진 자리 + 같은 자리 바꿔 끼우기 — WORLD.md 확정 2026-11-09).
- C6 유리병 + 기록 목록 [MVP] — 누적 구슬(줄지 않음) + 날짜별 목록. "돌아보기"가 서비스 목적의 절반.
  - 2026-11-10 (대표 결정, 앱 구현 완료): 구슬 50개가 차면 뚜껑을 닫아 유리병 화면 선반에 진열 + 새 병. 남은 개수 표시 없음. 닫힌 병 탭 = 기간·카테고리. 닫은 병을 방 소품으로 두는 건 마당 업데이트 때
  - J1 확정 (2026-11-10 대표 결정: A, 앱 구현 완료): 기록이 쌓일 때 유리병 화면 — 원문은 절대 줄이거나 요약으로 바꾸지 않고 '나눠서 보관'
    - (A) 병 = 앨범 ← 추천: 유리병 화면은 지금 병 + 이번 주 카드 + 최근 2주 기록만. 그 이전 기록은 선반의 닫힌 병을 열면 그 병의 50개를 날짜별 원문 그대로. 선반은 연도별 칸으로 접힘. + 기록 검색(글자로 찾기). 화면 길이가 항상 짧고 병 비유와 맞음 / 대신 '한 달 전 그날'을 찾으려면 병을 열거나 검색해야 함
    - (B) 달력: 월 달력에서 날짜 탭 → 그날 기록. 날짜로 찾기 쉬움 / 기록 안 한 날이 빈칸으로 줄지어 보여 '놓친 날' 압박 → 원칙과 충돌 위험
    - (C) 월별 접기 목록: 이번 달만 펼치고 지난달은 "10월 · 87가지" 한 줄 → 탭해서 펼침. 가장 단순 / 병과 따로 놀고 오래 쓰면 월 줄이 길어짐
    - (D) AI 요약으로 압축: 원문이 안 보이게 되므로 제외. 요약은 원문 위에 '덧붙이는' 용도(주간 카드 등)로만
    - 구현: 병 번호(wins.jar_no)는 기록하는 순간 서버가 고정, profiles.marbles_total = 넣은 구슬 수(지워도 안 줄어듦). 앱은 최근 13주 + 지금 병만 불러오고, 선반 병 열기(/jar/번호)·찾기(/jar/search, 최근 100개)·내보내기(전부 나눠 받기)는 서버에서 따로. 선반은 연도별 칸(올해만 펼침). 지난 날짜엔 연도 표시
    - (당시 메모) A를 하려면(개발): 기록마다 병 번호를 저장할 때 고정 → 지워도 다른 병 내용이 밀리지 않음. 앱이 기록을 최대 2,000개만 불러오는 지금 구조는 하루 5개 사용자 기준 약 1년 뒤 오래된 기록이 안 보이므로, 병·기간 단위로 서버에서 나눠 불러오도록 바꿔야 함
- C7 기록 수정·삭제 [MVP] — 오타, 실수 입력 대응. 삭제해도 이미 받은 씨앗은 회수하지 않음(잃는 장치 없음).
- C8 어제 기록 추가 [MVP] — 입력창에 "오늘/어제" 선택. 빼먹은 날을 "놓쳤다"가 아니라 "나중에 채울 수 있다"로 만듦. 구현 비용 작음.

- C9 기록 다시 보기 [MVP, M4만 출시 후] (2026-11-13 대표 결정, 시안 design/features/records_mock/) — 게임 쪽보다 본 기능(내 기록을 편하게 다시 보기)을 챙기는 묶음. 원문은 그대로, 덧붙이기만
  - M1 방 '오늘의 쪽지' (A): 입력창 아래 오늘 적은 기록이 쪽지(색 점 + 글 + 시각)로 쌓임. "다 보기" → 하루 한 장(오늘)
  - M2 보기 방식 (A + B 둘 다): 기록을 누르면 '크게 보기' 시트(읽기 먼저), 고치기·지우기는 ··· 안 / 분류별 모아 보기 / 하루 한 장(기록한 날만 좌우로 넘김, 빈 날 건너뜀)
    - N1 (A): 크게 보기를 열면 그때 단짝 동작이 작게 자동 재생. '동작 줄이기' 켜면 멈춘 그림, '버틴 하루'는 곁에 앉기 동작
    - N2 (A, 자해 감지 없이): 추가 메모 = 나중에 크게 보기 시트 안 "+ 한 줄 더 남기기"에서만(기록 입력창은 그대로 1줄). 새 화면 없음. 메모는 찾기·내보내기에 포함. 메모에는 자해 표현 감지를 돌리지 않음(대표 결정)
  - M3 (A) ☆ 다시 보고 싶은 기록: 크게 보기에서 ☆. 씨앗·구슬 차등 없음, 이름은 '큰 일'이 아니라 '다시 보고 싶은'
    - N3 (A): ☆ 칩 = 분류 칩 줄 맨 앞, 분류별 모아 보기와 같은 목록 화면(찾기 결과도 이 화면 모양으로 통일)
  - M4 (A) 돌아보기 카드 [출시 후]: '한 달 전 오늘'(그날 기록 있을 때만, 탭 → 크게 보기), '○월의 나' 카드(자주 한 일·처음 적은 일·다시 해낸 일, 지난달 비교 숫자 없음, 카드로 저장), 12월 '올해의 유리병'
    - N4 (A): 유리병 탭 맨 위 카드 자리는 하나 — 월초 1주는 한 달 카드 → 일요일은 주간 카드 → 나머지 날은 한 달 전 오늘. 지난 한 달 카드는 '지난 달 돌아보기'
  - 들어가는 길: 분류 칩/☆ 칩 → 목록 화면 / 목록 날짜 제목·쪽지 "다 보기" → 하루 한 장 / 어디서든 기록·구슬 누르면 → 크게 보기 시트. 화면은 유리병 탭 + 목록 화면 1개 + 하루 한 장, 깊어도 2단계 + 시트
  - N5 확정 (2026-11-13 대표 결정): 구슬 쓸어 보기 + 말풍선 + 진동 + "목록으로 보기" 링크 + 처음 안내 (시안 records_mock/sheet4.png)
    - 0.3초 꾹 누르면 시작(톡 진동, 그냥 밀면 화면 스크롤) → 손가락 아래 구슬이 바뀔 때마다 아주 약한 진동(iOS selection 진동, expo-haptics selectionAsync) + 구슬 위쪽 말풍선(손가락에 안 가리게) → 손 떼면 마지막 구슬 말풍선 유지 → 말풍선 탭 = 크게 보기 시트, 빈 곳 탭 = 닫힘. 구슬 짧게 톡 = 같은 말풍선
    - 병 아래 작은 "목록으로 보기" 링크 = 이 병 구슬 목록(넣은 순서, 줄 앞 점 = 구슬 색), 선반 병 열기(/jar/번호)와 같은 화면. 다 읽기·VoiceOver 사용자용
    - 처음 안내 "구슬을 꾹 누른 채로 쓸어 봐" — 한 번 쓸어 보면 사라짐
    - 선반 닫힌 병 열기 화면의 병도 같은 쓸어 보기 (일관성)
    - 진동 세기·손가락 대비 구슬 크기는 폰에서 대표 확인 (웹에선 진동 확인 불가)
  - (검토했던 대안, 참고)
    - (A) 병 그림 탭 → 이 병 구슬 목록(넣은 순서, 구슬 색 = 줄 앞 점). 선반 병 열기(/jar/번호)와 같은 화면 ← 추천: 한 번에 다 보이고 새 화면 거의 없음

    - (C) 병 탭 → 구슬 하나가 굴러 나와 기록 1개 + '하나 더 꺼내기': 다시 만나는 재미, 다 보는 용도는 아님

    - (B') 대표 제안 (2026-11-13, 시안 records_mock/sheet4.png, 확정 대기): 0.3초 꾹 누르면 시작(톡 진동, 그냥 밀면 화면 스크롤) → 쓸어 가는 동안 손가락 아래 구슬이 바뀔 때마다 약한 진동 + 구슬 위쪽 말풍선(손가락에 안 가리게) → 손 떼면 마지막 구슬 말풍선이 남음 → 말풍선 탭 = 크게 보기 시트, 빈 곳 탭 = 닫힘. 구슬 짧게 톡 = 같은 말풍선. 개발: expo-haptics selectionAsync, 구슬 히트 테스트 + 스크롤 잠금

### 부수 기능
- S1 온보딩 + 펫 이름 짓기 [MVP] — 3화면 이내. 이름 짓기는 애착을 만드는 가장 싼 장치.
- S2 가입 + 클라우드 저장 [MVP] — 처음부터 가입(D1 결정). Apple + 카카오 + 이메일 OTP(Supabase Auth). 기기를 바꿔도 기록 유지, 구독 연결도 쉬움. 가입 화면은 펫 인사 직후 1화면으로 짧게.
- S3 하루 알림 [MVP] — 리텐션의 기본. 상세는 4장.
- S4 주간 돌아보기 [MVP] — 앱 안 카드 + 일요일 알림. 상세는 4장.
- S5 자해 표현 대응 [MVP] — 출시 전 필수. 상세는 5장.
- S6 데이터 삭제 · 계정 삭제 [MVP] — 앱스토어 심사 요건(계정 생성 앱은 앱 안 삭제 필수) + 개인정보보호법. 상세는 5장.
- S7 내보내기(텍스트) [MVP] — 공유 시트로 전체 기록 텍스트 내보내기. 하루 작업량, "내 기록은 내 것" 신뢰 장치.
- S8 설정 [MVP] — 알림 on/off·시간, 펫 이름 변경, 개인정보처리방침, 문의, 도움받을 수 있는 곳(상담 번호).
- S9 이용 분석 이벤트 [MVP] — continue/kill 판단 근거(D1/D7 재방문, 기록 수). 기록 본문은 절대 분석 도구로 보내지 않음.
- S10 구글 로그인 + Android [이후] — Google Play 비공개 테스트(12명 × 14일) 필요. 외부 소셜 로그인을 넣으면 Apple 로그인도 함께 있어야 함(앱스토어 규정).
- S11 그날의 기억 [이후, 마당 업데이트] — "한 달 전 오늘 너는 ○○를 해냈어" 다시 보여주기. 마당 추억 나무 열매를 탭하면 나옴(7일 이상 지난 기록, '버틴 하루' 제외 권장). 7장
- S12 펫 성장(누적 기록 기준) [이후] — 기록 10·30·100개마다 새 동작/표정. 줄어들지 않는 성장만. 캐릭터 에셋 확정 후.
- S13 공유 카드 [이후] — 기록 1개를 예쁜 이미지로 저장/인스타 공유. 성장 채널. 숫자·비교 없이 기록 내용만.

## 4. 리텐션 장치 (잃는 장치 없이)

### 하루 알림 (S3)
- 권한 요청 시점: 첫 기록 직후 (첫날 축하를 겪은 뒤라 수락률이 높음). 거절해도 설정에서 다시 켤 수 있음.
- 하루 최대 1회, 사용자가 고른 시간. 그날 이미 기록했으면 보내지 않음.
- 7일 연속 앱을 열지 않으면 주 1회(일요일)로 자동 전환, 앱을 다시 열면 매일로 복귀. 부담 주지 않으면서 알림 끄기·앱 삭제를 막는 장치.
- 문구 규칙: 질문형·초대형만. 금지: 부재 언급, 숫자(며칠째), 죄책감("펫이 기다려요 ㅠㅠ"), 명령형.
- 문구는 10개 이상 돌려 쓰기. 예: "오늘 해낸 거 하나만 알려줄래?", "물 한 잔 마신 것도 승리야. 오늘은 뭐 했어?", "○○(펫 이름)가 오늘 이야기 듣고 싶대"
- 구현: Expo Notifications 로컬 예약 알림 (서버 푸시 불필요 → MVP 비용 0)

### 주간 돌아보기 (S4)
- 일요일 저녁(알림 시간과 같은 시각) 앱 안에 "이번 주 유리병" 카드 생성 + 알림 1회
- 내용: 이번 주 구슬(카테고리 색), "이번 주 너는 N가지를 해냈어", 카테고리별 개수, 이번 주 기록 중 무작위 1개 "이 순간 기억나?" ('버틴 하루' 기록은 여기 나오지 않음 — 2026-11-10 대표 결정)
- 기록 0개인 주: 리포트 대신 "이번 주에 한 가장 작은 일 하나만 떠올려볼래?" (실패 표시 없음)
- 금지: 지난주 대비 증감, 목표 대비 달성률, 평균과 비교
- 지난 주간 카드는 유리병 화면에서 다시 볼 수 있음

### 그 밖 (줄어들지 않는 것만 보여준다)
- 유리병 누적 구슬 수, 방에 늘어나는 소품, (이후) 펫 성장 — 모두 오르기만 함
- 일일 보상 상한(기록 10개)으로 파밍·과몰입 억제

## 5. 안전장치

### 자해·자살 표현 대응 (S5)
- 감지: 1차 기기 안 키워드(즉시, 오프라인), 2차 서버 LLM 분류(오탐 줄이기: "죽을 만큼 맛있었다" 등). LLM 실패 시 키워드 결과대로 안내를 보여줌(안전한 쪽으로 실패).
- 감지되면:
  - 기록은 그대로 저장, 씨앗도 똑같이 지급 (차등 없음 원칙 + "말하면 불이익" 학습 방지)
  - 폭죽·점프 대신 조용한 동작(펫이 곁에 앉음)과 한마디: "말해줘서 고마워. 오늘 버틴 것도 정말 큰 일이야."
  - 안내 카드: 자살예방상담전화 109 (24시간), 정신건강상담 1577-0199, 청소년 1388, 위급하면 112/119. 번호 누르면 바로 전화 연결.
  - 카드는 닫을 수 있음. 같은 날 다시 감지되면 작은 배너로만(반복 팝업은 오히려 거부감)
  - 자해 표현이 감지된 기록은 항상 '버틴 하루'로 저장('나 돌보기' 등으로 남지 않게, 2026-11-10)

### 버틴 하루 (2026-11-10 대표 결정, 앱 구현 완료)
- 9번째 분류 endure: 해낸 일이 아니라 힘든 마음을 털어놓은 기록("힘들다"). 해낸 일이 같이 있으면 그 일로 분류('힘들었지만 운동했다' → 운동)
- 저장 막지 않음, 씨앗 동일. 단짝은 축하 대신 곁에 3초 앉기, 상담 카드는 자해 감지 때만. 유리병 구슬은 차분한 색. 주간 카드 "이 순간 기억나?"에서 제외
- 상시: 설정 > "도움받을 수 있는 곳"에 같은 번호. 온보딩에서 "상담 서비스가 아니다" 고지.
- 로그: `safety_events`에 발생 시각만 기록(본문 저장 안 함) → 빈도 확인용. 운영자가 개별 사용자에게 연락하지 않음(처리방침에 명시).
- 출시 전 체크: 키워드 목록 50개 이상 + 테스트 문장 30개(진짜 위험 15 / 오탐 유도 15)로 감지 정확도 확인.
- 근거: 109는 2024-01-01부터 통합 운영되는 24시간 자살예방상담전화 (보건복지부 발표).

### 데이터 삭제 · 내보내기 (S6, S7)
- 기록 1개 삭제: 목록에서 밀어서 삭제, 확인 1회.
- 모든 기록 지우기: 설정 > 2단계 확인. wins 삭제, 펫·방·씨앗은 유지.
- 계정 삭제: 설정 > 2단계 확인 → Supabase Edge Function이 해당 사용자의 모든 행 + auth 사용자 즉시 삭제 → 앱 초기화. 백업에 남은 사본은 보관 주기 후 소멸(처리방침에 명시).
- 내보내기: 전체 기록을 "날짜 · 내용 · 카테고리" 텍스트로 공유 시트에 넘김.
- 기록 본문은 분류용 LLM에 보낼 때 사용자 식별자 없이 전송, LLM 제공사 국외 이전을 처리방침·온보딩 동의에 명시.
