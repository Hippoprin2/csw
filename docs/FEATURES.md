## 1. 기능 목록과 MVP 구분

표기: [MVP] 필수 · [이후] MVP 다음 · [보류] 근거가 생길 때까지 안 만듦 · [제외] 원칙 위반이라 만들지 않음

### 핵심 기능 (핵심 루프 그 자체)
- C1 성취 기록 [MVP] — 텍스트 1줄(최대 100자), 개수 무제한, 추천 칩 6개. 루프의 시작이라 빠지면 앱이 아님.
  - 정리 장치 (2026-11-08 결정, 횟수 제한·건당 결제 대신): 같은 날 같은 내용은 한 줄로 묶어 표시("물 마셨다 ×4", 구슬은 4개 그대로) / 기록 많은 날은 접어서 표시("오늘 23가지 · 펼치기") / 주간 돌아보기 하이라이트는 반복 적은 기록 우선 / 서버 남용 방지 하루 50개 (초과 시 "오늘은 충분히 많이 적었어, 내일 또 들려줘" 안내, 분류 AI 비용 상한 겸용)
- C2 동작 자동 분류 7종 + "바꾸기" [MVP] — 축하가 "내 일을 알아들었다"고 느끼게 하는 핵심. 키워드 즉시 분류 → 서버 LLM 보정, 실패 시 키워드 결과 유지.
- C3 펫 축하 애니메이션 + 한마디 [MVP] — 앱의 감정적 보상. 한마디는 카테고리별 템플릿(카테고리당 5~8개).
- C4 씨앗 보상 [MVP] — 기록 1개 = 씨앗 3개, 하루 10개 기록까지 보상(최대 30), 기록은 무제한. 모든 기록 같은 양.
- C5 방 꾸미기 [MVP] — 씨앗으로 소품 구매·자동 배치. MVP는 방 1개 + 소품 15~20개(첫 주 안에 다 못 사는 양).
- C6 유리병 + 기록 목록 [MVP] — 누적 구슬(줄지 않음) + 날짜별 목록. "돌아보기"가 서비스 목적의 절반.
- C7 기록 수정·삭제 [MVP] — 오타, 실수 입력 대응. 삭제해도 이미 받은 씨앗은 회수하지 않음(잃는 장치 없음).
- C8 어제 기록 추가 [MVP] — 입력창에 "오늘/어제" 선택. 빼먹은 날을 "놓쳤다"가 아니라 "나중에 채울 수 있다"로 만듦. 구현 비용 작음.

### 부수 기능
- S1 온보딩 + 펫 이름 짓기 [MVP] — 3화면 이내. 이름 짓기는 애착을 만드는 가장 싼 장치.
- S2 가입 + 클라우드 저장 [MVP] — 처음부터 가입(D1 결정). Apple + 카카오 + 이메일 OTP(Supabase Auth). 기기를 바꿔도 기록 유지, 구독 연결도 쉬움. 가입 화면은 펫 인사 직후 1화면으로 짧게.
- S3 하루 알림 [MVP] — 리텐션의 기본. 상세는 4장.
- S4 주간 돌아보기 [MVP] — 앱 안 카드 + 일요일 알림. 상세는 4장.
- S5 자해 표현 대응 [MVP] — 출시 전 필수. 상세는 5장.
- S6 데이터 삭제 · 계정 삭제 [MVP] — 앱스토어 심사 요건(계정 생성 앱은 앱 안 삭제 필수) + 개인정보보호법. 상세는 5장.
- S7 내보내기(텍스트) [MVP] — 공유 시트로 전체 기록 텍스트 내보내기. 하루 작업량, "내 기록은 내 것" 신뢰 장치.
- S8 설정 [MVP] — 알림 on/off·시간, 펫 이름 변경, 개인정보처리방침, 문의, 도움받을 수 있는 곳(상담 번호).
- S9 이용 분석 이벤트 [MVP] — continue/kill 판단 근거(D1/D7 재방문, 기록 수). 기록 본문은 절대 분석 도구로 보내지 않음.
- S10 구글 로그인 + Android [이후] — Google Play 비공개 테스트(12명 × 14일) 필요. 외부 소셜 로그인을 넣으면 Apple 로그인도 함께 있어야 함(앱스토어 규정).
- S11 그날의 기억 [이후] — "한 달 전 오늘 너는 ○○를 해냈어" 다시 보여주기. 돌아보기 강화, 기록이 쌓여야 의미 있음.
- S12 펫 성장(누적 기록 기준) [이후] — 기록 10·30·100개마다 새 동작/표정. 줄어들지 않는 성장만. 캐릭터 에셋 확정 후.
- S13 공유 카드 [이후] — 기록 1개를 예쁜 이미지로 저장/인스타 공유. 성장 채널. 숫자·비교 없이 기록 내용만.
- S14 홈 화면 위젯 [이후] — 펫 + "오늘 해낸 일" 바로 입력. 재방문 효과 크지만 Expo 네이티브 작업 필요.
- S15 LLM 맞춤 한마디 [이후] — 템플릿보다 반응이 좋을 수 있지만 엉뚱하거나 부적절한 답 위험. 안전 필터 검증 후.
- S16 사진 첨부 [이후] — 저장 비용·개인정보 부담. 텍스트 루프 검증 후.
- S17 음성 기록 [이후] — 이미 결정된 MVP 제외 항목.
- S18 펫/동물 여러 종 선택 · 여러 방/마을 [이후] — CHARACTER/WORLD 스레드 결정에 따름. MVP는 1종 + 방 1개 제안.
- S19 다크 모드 · 영어 [이후]
- S20 목표 → 작은 단계 쪼개기 [보류] — 장기 목적(행동 습관)이지만 "목표 미달" 감정을 다시 불러올 위험. 기록 습관이 먼저 검증돼야 함.
- S21 기분/감정 태그 [보류] — 무드 트래커로 범위가 흐려짐. 사용자 요청이 반복되면 재검토.
- S22 결제·구독 [보류] — 사업자등록 전. MONETIZATION.md에서 결정.
- S23 친구·공유 광장 [보류] — 비교·경쟁 위험 + 게시물 관리 부담. 이미 MVP 제외로 결정됨.
- S24 웹 버전 [보류] — 앱으로 결정됨.
- X1 스트릭(연속 기록 일수) [제외] — 끊기는 순간 잃는 장치.
- X2 순위·랭킹·친구와 비교 [제외] — 경쟁 금지.
- X3 펫 배고픔/아픔/떠남, 미접속 패널티 [제외] — 잃는 장치.
- X4 성취 크기별 보상(큰 일 = 씨앗 많이) [제외] — 차등 금지.
- X5 "지난주보다 적어요" 같은 기간 비교 [제외] — 과거의 나와의 경쟁도 자책을 부름.

## 2. MVP 범위 요약
기록(C1, C8) → 분류(C2) → 축하(C3) → 씨앗(C4) → 꾸미기(C5) → 돌아보기(C6, C7)
+ 온보딩(S1), 익명 계정(S2), 하루 알림(S3), 주간 돌아보기(S4), 안전장치(S5, S6, S7), 설정(S8), 분석(S9)

Supabase 테이블 초안: `profiles`(pet_name, notify_time, created_at) · `wins`(user_id, text, category, category_source[auto|user], win_date, created_at) · `seed_ledger`(user_id, delta, reason) · `items` / `owned_items` · `safety_events`(user_id, created_at — 본문 저장 안 함). 전 테이블 RLS로 본인 행만.

## 3. 핵심 사용 흐름

### 첫 실행 (목표: 60초 안에 첫 축하)
1. 스플래시 → 펫이 인사: "안녕! 오늘 해낸 걸 알려줘. 아주 작은 것도 좋아."
1-1. 가입 1화면: Apple로 계속하기 / 카카오로 계속하기 / 이메일로 계속하기 (+ 약관·개인정보·14세 이상 동의)
2. 이름 짓기 1화면 (기본 이름 제시, 건너뛰기 가능)
3. 한 줄 안내: "침대 정리도, 물 한 잔도 다 승리야. 크기는 상관없어." + "14세 이상 이용 / 상담 서비스가 아님 / 개인정보 처리" 고지·동의 1화면 (D4)
4. 바로 방으로

### 첫 기록
5. 입력창 + 추천 칩 6개. 칩 하나 누르면 바로 기록 가능 → 첫 기록 장벽 제거
6. 입력하면 "○○ 동작을 할 거예요 · 바꾸기" 표시 → 저장
7. 펫 동작 + 한마디 + "+3 씨앗" → 첫 기록만 추가 연출: "첫 구슬이 유리병에 들어갔어!"
8. 온보딩 선물 씨앗 6개를 더해 바로 첫 소품(9씨앗 화분 등) 구매 가능 → 꾸미기 루프를 첫날 경험
9. 그 다음에 알림 권한 요청 (D5): "내일 이 시간쯤 한 번만 물어봐도 될까?" → 허용 시 시간 선택(기본 21:00)

### 다음 날 다시 오기
10. 알림(설정 시간 1회): 펫 말투로 "오늘 해낸 거 하나만 알려줄래?" (부재·숫자 언급 없음)
11. 열면 펫 인사 + 어제 넣은 구슬이 유리병에 보임 (쌓인 것 확인)
12. 기록 → 축하 → 씨앗 → 소품. 어제 빼먹었으면 "어제" 선택해서 채울 수 있음
13. 며칠 쉬다 와도 똑같은 인사. "오랜만이야", "N일 만이야" 같은 문구 금지

## 4. 리텐션 장치 (잃는 장치 없이)

### 하루 알림 (S3)
- 권한 요청 시점: 첫 기록 직후 (첫날 축하를 겪은 뒤라 수락률이 높음). 거절해도 설정에서 다시 켤 수 있음.
- 하루 최대 1회, 사용자가 고른 시간. 그날 이미 기록했으면 보내지 않음.
- 7일 연속 앱을 열지 않으면 주 1회(일요일)로 자동 전환, 앱을 다시 열면 매일로 복귀. 부담 주지 않으면서 알림 끄기·앱 삭제를 막는 장치.
- 문구 규칙: 질문형·초대형만. 금지: 부재 언급, 숫자(며칠째), 죄책감("펫이 기다려요 ㅠㅠ"), 명령형.
- 문구는 10개 이상 돌려 쓰기. 예: "오늘 해낸 거 하나만 알려줄래?", "물 한 잔 마신 것도 승리야. 오늘은 뭐 했어?", "○○(펫 이름)가 오늘 이야기 듣고 싶대"
- 구현: Expo Notifications 로컬 예약 알림 (서버 푸시 불필요 → MVP 비용 0)

### 주간 돌아보기 (S4)
- 일요일 저녁(알림 시간과 같은 시각) 앱 안에 "이번 주 유리병" 카드 생성 + 알림 1회
- 내용: 이번 주 구슬(카테고리 색), "이번 주 너는 N가지를 해냈어", 카테고리별 개수, 이번 주 기록 중 무작위 1개 "이 순간 기억나?"
- 기록 0개인 주: 리포트 대신 "이번 주에 한 가장 작은 일 하나만 떠올려볼래?" (실패 표시 없음)
- 금지: 지난주 대비 증감, 목표 대비 달성률, 평균과 비교
- 지난 주간 카드는 유리병 화면에서 다시 볼 수 있음

### 그 밖 (줄어들지 않는 것만 보여준다)
- 유리병 누적 구슬 수, 방에 늘어나는 소품, (이후) 펫 성장 — 모두 오르기만 함
- 일일 보상 상한(기록 10개)으로 파밍·과몰입 억제

## 5. 안전장치

### 자해·자살 표현 대응 (S5)
- 감지: 1차 기기 안 키워드(즉시, 오프라인), 2차 서버 LLM 분류(오탐 줄이기: "죽을 만큼 맛있었다" 등). LLM 실패 시 키워드 결과대로 안내를 보여줌(안전한 쪽으로 실패).
- 감지되면:
  - 기록은 그대로 저장, 씨앗도 똑같이 지급 (차등 없음 원칙 + "말하면 불이익" 학습 방지)
  - 폭죽·점프 대신 조용한 동작(펫이 곁에 앉음)과 한마디: "말해줘서 고마워. 오늘 버틴 것도 정말 큰 일이야."
  - 안내 카드: 자살예방상담전화 109 (24시간), 정신건강상담 1577-0199, 청소년 1388, 위급하면 112/119. 번호 누르면 바로 전화 연결.
  - 카드는 닫을 수 있음. 같은 날 다시 감지되면 작은 배너로만(반복 팝업은 오히려 거부감)
- 상시: 설정 > "도움받을 수 있는 곳"에 같은 번호. 온보딩에서 "상담 서비스가 아니다" 고지.
- 로그: `safety_events`에 발생 시각만 기록(본문 저장 안 함) → 빈도 확인용. 운영자가 개별 사용자에게 연락하지 않음(처리방침에 명시).
- 출시 전 체크: 키워드 목록 50개 이상 + 테스트 문장 30개(진짜 위험 15 / 오탐 유도 15)로 감지 정확도 확인.
- 근거: 109는 2024-01-01부터 통합 운영되는 24시간 자살예방상담전화 (보건복지부 발표).

### 데이터 삭제 · 내보내기 (S6, S7)
- 기록 1개 삭제: 목록에서 밀어서 삭제, 확인 1회.
- 모든 기록 지우기: 설정 > 2단계 확인. wins 삭제, 펫·방·씨앗은 유지.
- 계정 삭제: 설정 > 2단계 확인 → Supabase Edge Function이 해당 사용자의 모든 행 + auth 사용자 즉시 삭제 → 앱 초기화. 백업에 남은 사본은 보관 주기 후 소멸(처리방침에 명시).
- 내보내기: 전체 기록을 "날짜 · 내용 · 카테고리" 텍스트로 공유 시트에 넘김.
- 기록 본문은 분류용 LLM에 보낼 때 사용자 식별자 없이 전송, LLM 제공사 국외 이전을 처리방침·온보딩 동의에 명시.

## 6. 결정 필요 (선택지 · 추천)
- D1 계정 방식: 결정됨(2026-11-08) — 처음부터 가입 필수
- D2 펫 한마디: (A) 카테고리별 템플릿 ← 추천 (안전·비용 0, 자해 표현에 엉뚱한 답 위험 없음) / (B) LLM 생성 (더 개인적, 검증 비용 큼) → B는 S15로 이후 실험
- D3 분류: (A) 키워드 + 서버 LLM 보정 ← 추천 (GAME_DESIGN 결정 유지, 1건당 비용 극소) / (B) 키워드만 (본문이 서버 밖으로 안 나감, 분류 정확도 낮음)
- D4 이용 연령: (A) 14세 이상 ← 추천 (14세 미만은 법정대리인 동의 절차 필요) / (B) 전 연령 (동의 절차 구현 필요)
- D5 알림 권한 요청 시점: (A) 첫 기록 직후 ← 추천 / (B) 온보딩 중
- D6 주간 돌아보기 위치: (A) 앱 안 카드 + 알림 ← 추천 (이메일 수집 불필요) / (B) 이메일 리포트
