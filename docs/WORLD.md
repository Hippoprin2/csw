## 1. 공간 구성과 레이아웃

### 공통
- 순서(W1): 텃밭 ← **방(홈)** → 마당. 앱을 열면 방. 마당이 잠겨 있으면 오른쪽 끝에 울타리 문 + "기록한 날 7일이면 열려"(연속 아니어도 됨, 줄지 않음). 남은 개수 카운트다운("3개 남음")은 넣지 않고 문 너머로 마당이 살짝 보이는 그림으로 대신함
- 화면 배치(세로): 방 = 위 상태줄 / 공간 그림 / 아래 입력창 + 추천 칩(입력창이 바닥 앞쪽을 살짝 덮어도 됨, 앞쪽 1/6에는 소품 두지 않음). 텃밭·마당 = 입력창 없이 공간 그림이 더 크게 보임(아래는 심기·수확 버튼 등 그 공간 조작만)
- 카메라(W2, 확정): 직교 카메라, 방향 = ART_BIBLE의 3/4 방향(0.35, -1, 고도). **방 = 고도 0.12(6.5°, 캐릭터 기본과 같음), 텃밭·마당 = 고도 0.5(25°, 책상 장면 최고점과 같음).** 직교라서 같은 고도로 렌더한 단짝을 공간 그림 위에 크기만 맞춰 얹으면 시점이 정확히 맞는다
  - 결과: 방은 기존 6.5° 단짝 클립(export v1) 그대로. 입력창이 방에만 있어서 축하 8종·곁에 앉기는 25°로 만들 필요 없음
  - 25°로 새로 렌더할 것: 출시(텃밭) = 대기 + 만세(수확할 때) 2개, 약 +1.2MB / 마당 업데이트 때 = 걷기 3방향(앞·뒤·옆), 벤치 앉기, 매트에 앉아 먹기, 해먹 눕기, 물장구, 냄새 맡기, 열매 보여주기 (7장 표)
  - 방 6.5°에서는 바닥이 얇게 보임 → 러그는 얇은 띠로만 보임(유지), 바닥 소품은 키 있는 것 위주
  - 확정 화면 시안: design/world/blockout/v2/decided_room6_garden25_yard25.png
  - 단짝 크기: 공간 1개 너비 ≈ 단짝 키 3.2~3.5배 (화면 높이의 약 20%)
  - 비교 시안(v1, 색이 밝게 날아간 버전 — 아래 '시안' 참고): design/world/blockout/camera_compare.png, yard_compare.png
- 그림 방식: 배경 1장 + 소품마다 "제자리에서 렌더한 투명 이미지" 1장을 겹침(미리 렌더, 앱 형식 A와 같음). 소품 이미지는 같은 카메라로 전체 화면을 렌더한 뒤 테두리만 잘라 위치(x, y, w, h)와 층(뒤/가운데/앞)을 JSON으로 같이 내보냄 → 앱은 JSON대로 그리면 끝 (mobile/src/data/itemSlots.ts 대체)
  - 층: 뒤(벽·뒤 가구) → 단짝 → 앞(앞줄 소품). 단짝 자리(방 가운데)와 책상 동작 팝인 자리는 러그 말고 비워 둠

- 각 구역은 자기 소품 세트와 함께 업데이트로 나옴(2구역 = 2차 업데이트). 구역만 있고 소품이 없으면 살 이유가 약함
- 구역 가격 계산(sim, 출시 사용자, 다 채운 뒤 사는 경우): 60·120 → 열심 8.4주·10.6주 / 보통 19주·24주 / 가벼움 47주 이후. 가벼운 사용자는 1구역만으로도 완결된 마당이어야 함
- 걷기 데이터(walk)는 구역별 다각형을 합쳐서 씀. 구역 사이는 길(징검돌)로 이어짐
- 캔버스(확정 배치): 2160×3100 px — 1구역 (0,0,1080,1860) 집 앞마당 / 2구역 오른쪽 (1080,0,1080,1860) 개울가(개울 + 징검돌 + 버드나무 + 갈대) / 3구역 아래 (0,1860,1080,1240) 꽃언덕 숲길(꽃언덕 + 흙길 + 버섯) / 4 오른쪽 아래 = 숲 풍경(걷지 않음, 판매 안 함). 앞마당의 징검돌 길이 2구역 문(오른쪽)과 3구역 문(아래)으로 이어짐
- 화면 이동(확정): 단짝을 부드럽게 따라감 + 손가락으로 끌어 둘러보기(손 떼고 3초 뒤 단짝에게 복귀). 탭 = 단짝이 걸어감. 화면은 산 구역 + 잠긴 이웃 구역으로 600px까지만(울타리 너머 풍경이 보이게). 대표 테스트 후 수치(2026-11-10): 따라가기 0.3, 여유 범위 120px, 복귀 대기 3초, 복귀 1.2초 천천히, 두 손가락 줌아웃 최대 0.6배. 수치는 export manifest `spaces.yard.camera`
