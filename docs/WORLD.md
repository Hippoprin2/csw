## 1. 공간 구성과 레이아웃

### 공통
- 순서(W1): 텃밭 ← **방(홈)** → 마당. 앱을 열면 방. 마당이 잠겨 있으면 오른쪽 끝에 울타리 문 + "구슬 10개면 열려". 남은 개수 카운트다운("3개 남음")은 넣지 않고 문 너머로 마당이 살짝 보이는 그림으로 대신함
- 화면 배치(세로): 방 = 위 상태줄 / 공간 그림 / 아래 입력창 + 추천 칩(입력창이 바닥 앞쪽을 살짝 덮어도 됨, 앞쪽 1/6에는 소품 두지 않음). 텃밭·마당 = 입력창 없이 공간 그림이 더 크게 보임(아래는 심기·수확 버튼 등 그 공간 조작만)
- 카메라(W2, 확정): 직교 카메라, 방향 = ART_BIBLE의 3/4 방향(0.35, -1, 고도). **방 = 고도 0.12(6.5°, 캐릭터 기본과 같음), 텃밭·마당 = 고도 0.5(25°, 책상 장면 최고점과 같음).** 직교라서 같은 고도로 렌더한 단짝을 공간 그림 위에 크기만 맞춰 얹으면 시점이 정확히 맞는다
  - 결과: 방은 기존 6.5° 단짝 클립(export v1) 그대로. 입력창이 방에만 있어서 축하 8종·곁에 앉기는 25°로 만들 필요 없음
  - 25°로 새로 렌더할 것: 출시(텃밭) = 대기 + 만세(수확할 때) 2개, 약 +1.2MB / 마당 업데이트 때 = 걷기 3방향, 앉기, 물장구, 눕기, 냄새 맡기
  - 방 6.5°에서는 바닥이 얇게 보임 → 러그는 얇은 띠로만 보임(유지), 바닥 소품은 키 있는 것 위주
  - 확정 화면 시안: design/world/blockout/v2/decided_room6_garden25_yard25.png
  - 단짝 크기: 공간 1개 너비 ≈ 단짝 키 3.2~3.5배 (화면 높이의 약 20%)
  - 비교 시안(v1, 색이 밝게 날아간 버전 — 아래 '시안' 참고): design/world/blockout/camera_compare.png, yard_compare.png
- 그림 방식: 배경 1장 + 소품마다 "제자리에서 렌더한 투명 이미지" 1장을 겹침(미리 렌더, 앱 형식 A와 같음). 소품 이미지는 같은 카메라로 전체 화면을 렌더한 뒤 테두리만 잘라 위치(x, y, w, h)와 층(뒤/가운데/앞)을 JSON으로 같이 내보냄 → 앱은 JSON대로 그리면 끝 (mobile/src/data/itemSlots.ts 대체)
  - 층: 뒤(벽·뒤 가구) → 단짝 → 앞(앞줄 소품). 단짝 자리(방 가운데)와 책상 동작 팝인 자리는 러그 말고 비워 둠

### 방 (출시)
- 크기(단짝 키 = 1): 너비 3.1, 깊이 1.95, 벽 높이 1.9. 뒷벽 + 왼쪽 벽이 보이는 모서리 방(디오라마)
- 기본(무료, 처음부터): 나무 바닥, 크림 벽, 창문, **창턱 수확 선반**(수확물 장식 자리 3칸), 문(텃밭/마당으로 이어지는 느낌)
- 소품 자리 14개 (자리마다 1개 표시, 같은 자리 소품을 여러 개 가지면 탭해서 바꿔 끼움 — W3)
  - 벽: 창문(커튼) / 왼쪽 벽(액자) / 오른쪽 벽(벽시계) / 벽 위(가랜드 · 전구줄) / 천장(모빌)
  - 뒤 가구: 뒤-왼쪽(침대) / 뒤-오른쪽(책장) / 침대 옆(협탁+라디오 · 어항) / 책장 옆 벽 기대기(기타 · 이젤)
  - 바닥: 가운데(러그) / 오른쪽 가운데(좌식 탁자)
  - 앞줄: 앞-왼쪽(스탠드) / 앞-오른쪽(큰 화분) / 앞-가운데(쿠션 · 다람쥐 인형)
- 단짝 자리: 가운데, 러그 위. 방에서는 고정(걷지 않음)

### 텃밭 (출시)
- 크기: 너비 3.2, 깊이 2.2. 잔디 바닥, 뒤에 흰 울타리 + 둥근 생울타리, 팻말, 물뿌리개(장식)
- 밭 3칸, 처음부터 모두 열림(W4). 단짝은 밭 앞 가운데에 서서 대기, 수확할 때 만세
- 밭 칸 상태: 빈 칸("심기" 버튼) → 심음 → 싹 → 자람 → 다 자람(반짝임, 탭하면 수확 + 단짝 만세)
- 기록한 날마다 작은 변화: 그림 단계는 3일마다 바뀌고, 사이 날에는 진행 점(●●○)과 앱에서 살짝 커지는 효과(+5%)로 표현 → 그림 수를 늘리지 않음
- 졸고 있음: 3일 이상 미접속 시 단계 그림의 "고개 숙인" 버전 + Zzz 말풍선. 탭하면 앱 애니메이션(쭉 펴지기)으로 깸, 진행 영향 없음

### 마당 (첫 업데이트)
- 크기: 너비 4.0, 깊이 3.0. 잔디, 뒤 생울타리, 나무 1그루, 징검다리 길, 작은 연못(기본 무료)
- 단짝이 다닐 수 있는 영역: 잔디 전체에서 ① 연못 ② 나무 밑동 ③ 놓인 소품 바닥 면적(소품마다 정의) ④ 화면 앞 1/6(조작 버튼 밑) ⑤ 뒤 생울타리 앞 0.3을 뺀 다각형. 탭한 곳이 영역 밖이면 가장 가까운 안쪽 점으로
- 단짝 행동: 대기 4~8초 → 영역 안 무작위 지점으로 걷기 → 가끔(3번에 1번) 상호작용 소품으로 가서 동작 5~10초. 탭하면 하던 걸 멈추고 그 자리로 걸어옴. (마당에는 입력창이 없어서 축하 동작 없음)
- 상호작용 소품은 "들어가는 점(x, y)과 방향"을 가짐. 걷기는 좌·우(좌우 반전)·앞·뒤 4방향 = 렌더 3종

## 3. 씨앗 경제

### 가정 (FEATURES 7장과 같은 사용자 유형)
- 가벼움: 주 3일, 기록 4개 → 12씨앗/주
- 보통: 주 5일, 기록 10개 → 30씨앗/주
- 열심: 매일, 기록 21개 → 63씨앗/주
- 최대: 매일 10개 → 210씨앗/주 (상한)
- 텃밭: 3칸 계속 심으면 수확 = 3 × (기록한 날 ÷ 9) → 가벼움 1개/주, 보통 1.7개/주, 열심 2.3개/주. 기록 수가 아니라 기록한 날 기준이라 많이 써도 빨라지지 않음(차등 없음). 심기 비용은 주 3~7씨앗

### 첫날
- 선물 6 + 첫 기록 3 = 9 → 9씨앗 소품 1개 바로 구매(가장 싼 소품 = 9). 첫 작물(고구마)은 무료라 첫날 심고 다음 날 수확

### 방 소품 18개(264씨앗)를 사는 속도 (가장 싼 것부터 산다고 가정)
- 가벼움: 1주 2개 · 4주 6개 · 전부 22주 (텃밭도 하면 1주 1개 · 4주 4개 · 29주)
- 보통: 1주 4개 · 4주 11개 · 전부 9주 (텃밭도 하면 1주 3개 · 4주 10개 · 11주)
- 열심: 1주 7개 · 4주 17개 · 전부 5주
- 최대: 1주 16개 · 전부 2주 → 누구도 첫 주에 다 못 삼(264 > 첫 주 최대 216)
- 체험 7일 끝날 때 보통 사용자: 방 소품 3~4개 + 텃밭 수확 1~2개 → 방이 "채워지기 시작한" 상태에서 구독 결정
- 출시 후 실제 1인당 주간 기록 수(S9)로 가격 다시 맞춤. 가격은 items 테이블 값만 바꾸면 됨

### 남는 씨앗 (장기)
- 열심 사용자는 5주 차에 방을 다 채움 → 마당 업데이트(192씨앗)가 출시 후 4~5주 안에 나와야 씨앗이 쌓이기만 하는 구간이 짧음
- 그 다음 씨앗 쓰는 곳: 새 작물·새 소품(업데이트), 텃밭 심기(반복 3씨앗). 씨앗은 쌓여도 사라지지 않음

### 유료 꾸미기와의 관계 (유료화 스레드 참고용, 결정은 MONETIZATION.md)
- 자리(slot) 구조라서 "테마 세트" = 같은 자리에 끼우는 다른 모양(예: 바다 방 세트 = 침대·러그·액자… 바다 버전)으로 만들기 쉬움
- 원칙상 기간 한정 판매 금지 → 테마는 한번 나오면 계속 구매 가능. 계절 테마도 상시 판매
- 씨앗은 돈으로 팔지 않음(기록으로만). 유료 테마는 씨앗 상점과 별도 칸
