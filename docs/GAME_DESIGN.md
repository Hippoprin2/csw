# CSW 게임 디자인 v0 (2026-10-19)

## 서비스 소개
CSW(Celebrate Small Wins, 가칭)는 일상의 작은 성취를 기록하고, 돌아보고, 기억하고, 축하하는 앱이다.

### 만든 이유
- 대표가 직접 겪은 일에서 시작했다. 너무 크고 궁극적인 목표를 세우니 압도됐고, 해내지 못할 때마다 스스로를 탓하게 됐다.
- 필요했던 건 억지로 밀어붙이는 힘이 아니라, 작은 목표와 성취부터 시작하는 것이었다. 그래서 아침에 일어나 침대 정리하기부터 시작했다.

### 대상 사용자
- 자신에게 너무 엄격해서 목표를 이루지 못한다고 느끼는 사람
- 최종 목표를 이룬 것만 성취로 보는 사람
- 자존감이 낮아서 의미 있는 일을 하나도 하지 못했다고 느끼는 학생, 직장인, 엄마, 아빠
- (첫 테스트에서 집중할 그룹은 아직 정하지 않았다)

### 목적
- 크기나 영향력과 상관없이 모든 성취, 승리, 완료한 일을 기록하게 돕는다.
- 아주 작은 성취도 스스로 인정하게 해서 자존감과 자신감을 높인다.
- 장기적으로는 목표를 세우고 행동으로 옮기는 습관까지 이어지게 한다.

### 가설 (검증 필요)
- 작은 성취를 매일 기록하면 동기, 자존감, 목표 설정과 실행이 좋아질 것이다. 이 가설은 아직 리서치와 사용자 테스트로 확인해야 한다.

## 핵심 루프
1. 오늘 해낸 일 기록 (텍스트만. 음성은 MVP에서 제외)
2. 펫이 그 일과 비슷한 동작으로 축하 + 한마디
3. 씨앗 보상 (기록 1개 = 3개, 하루 10개까지 보상, 기록 자체는 무제한)
4. 씨앗으로 방/펫 꾸미기
5. 유리병/기록 목록에서 돌아보기

## 원칙 (취지 지키기)
- 성취 크기로 차등 없음: "침대 정리"와 "승진"이 같은 보상
- 잃는 장치 없음: 스트릭 끊김, 펫 아픔/죽음, 미접속 패널티 금지
- 꾸미기 보상만, 순위/경쟁 없음
- 하루 보상 상한으로 파밍 억제

## 펫
- 동물 컨셉. 프로토타입은 "꼬마하마" (임시, 그림은 SVG 플레이스홀더)
- 최종 캐릭터/이름은 미정

## 공통 애니메이션 7종 (모든 행위를 개별 구현하지 않음)
| 카테고리 | 예시 | 동작 | 소품 |
|---|---|---|---|
| 정리·청소 | 침대 정리, 설거지 | 좌우로 쓱싹 | 빗자루 |
| 몸 움직이기 | 산책, 스트레칭 | 점프 | 땀방울 |
| 공부·일 | 책 읽기, 업무 | 고개 끄덕 | 책 |
| 잘 먹기 | 아침 먹기, 물 마시기 | 냠냠 | 주먹밥 |
| 나 돌보기 | 샤워, 일찍 자기 | 기지개 + 회전 | 반짝이 |
| 사람·마음 | 엄마한테 전화 | 손 흔들기 | 편지 |
| 그 밖의 승리 | 나머지 전부 | 만세 + 점프 | 폭죽 |

- 분류: 프로토타입은 키워드 매칭. 실제 앱은 저렴한 LLM 분류 + 키워드 폴백. 사용자가 "바꾸기"로 직접 수정 가능.
- 나중에 늘릴 때는 카테고리 안에서 소품만 바꾸는 방식(침대→이불, 설거지→접시)으로 저비용 확장.

## 화면
- 방 (펫 + 기록 입력 + 추천 칩)
- 유리병 (최근 기록 구슬 + 날짜별 목록)
- 꾸미기 (씨앗 상점)
